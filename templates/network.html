Ethernet configuration

Current addresses above are live observations, not proof of configured DHCP/static mode. This form is a new configuration.

Change plan and reconnect procedure

Validate IPv4 values, back up /etc/dhcpcd.conf to /etc/dhcpcd.conf.flexclock-backup, replace only the tagged eth0 block, then run:

dhcpcd -n eth0

For static mode, reconnect at http://NEW_IP/. For DHCP, look up the assigned address in your router. No automated Ethernet testing is permitted.
